## Tracks

### Track 01: Enterprise Context + Ontology
Turn messy enterprise data into clean, queryable knowledge graph.
- 500K documents from 9 sources (Slack, Gmail, Linear, Google Drive, HubSpot, Fireflies, GitHub, Jira, Confluence)
- Hard part: entity resolution and ontology alignment
- Datasets: Enterprise RAG Bench, Salesforce HERB

### Track 02: Repos, Dependencies and Code as Graphs
A: Supply chain blast radius — npm/PyPI dependency graph, compromised packages
B: Code graphs for IDE assistants — call chains, type definitions, configs

### Track 03: Memory and Context Retrieval
Agent memory layer for cross-session continuity.
- 30-40 sessions, 115K tokens per question
- Synthesize facts, chronological order, track overwrites
- Datasets: LongMemEval, LongMemEval V2, BEAM
