## What we're working with

HydraDB is:
- PostgreSQL-compatible (speaks wire protocol, parses real SQL)
- Graph-native (ontologies, agent memory, context graphs)
- Object storage backend (10x lower cost)
- Has live connectors (Slack, Notion, GitHub, Gmail)
- Built for AI agents and knowledge systems

Our existing work:
- Research CI (dependency-based freshness for agent knowledge)
- Trace-to-dependency compiler
- Blast-radius propagation
- Proof obligations + verification receipts

## The overlap

HydraDB stores agent memory as graphs. Research CI adds dependency tracking + freshness.

Combined: **agents that know when their memories are stale.**
